# Logica-Na-Pratica-07

🖥️ Sobre o Projeto Neste projeto abordamos a implementação prática de automação industrial, estruturação de código, tratamento de intertravamentos, POUs (Program Organization Units) e validação de processos via simulação virtual em tempo real.

🎥 Assista à aula completa no YouTube:(https://youtu.be/l0AXUJWjehk)

💡 Como Utilizar

  Clone o repositório ou faça o download dos arquivos compactados.
   Abra os arquivos da pasta Factory io no seu software Factory I/O.
  Carregue o projeto correspondente no ambiente de desenvolvimento CODESYS e estabeleça a conexão via OPC UA.
  Execute a simulação e valide o funcionamento prático da lógica!
